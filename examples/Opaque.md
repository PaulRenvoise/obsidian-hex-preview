# Opaque colors

Inline code: `#23264F`, `#FFFFFF`, `#000000`.

Plain text: #23264F and #aAbBcC.

These should not have previews: `#abc`, `#abcd`, `#1234567`, `#123456789`, `#gggggg`.

The link should stay unchanged: [#23264F](https://example.com/#23264F).

```css
/* Fenced code is deliberately excluded. */

```
